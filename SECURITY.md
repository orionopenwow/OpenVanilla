# Security policy

Please report vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/orionopenwow/OpenVanilla/security/advisories/new) form,
or ask a moderator on the Open Vanilla Discord for a private channel. Don't open a public issue for security bugs.

In scope: the launcher (`launcher/`), the website (`www/`), the web backend (`asset_server.py`, `authcheck.py`)
and the server package. We reply within a week and credit reporters in the patch notes on request.

See also https://openvanilla.app/security.html and the [privacy policy](https://openvanilla.app/privacy.html).
