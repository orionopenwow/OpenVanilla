# Add a custom NPC or vendor

A new vendor on your own server, written as a reviewable SQL file first.

Works on: Your own servers only (the world database on this PC).

## Prompt

```text
Read CLAUDE.md. On my own <Play Solo / hosted> realm, add a custom vendor NPC called <name> who sells <items>. Use a new entry number above 190000, write the change as a .sql file in Agent\sql\ first and explain it to me before running anything, back up what you touch, and tell me the GM command to spawn the NPC where I stand (.npc add <entry>) and how to remove it again.
```

## Tips

- You need a GM account on your realm to spawn it: see the GM commands in CLAUDE.md.
