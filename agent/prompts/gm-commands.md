# GM commands cheat sheet

Make yourself a GM on your own realm and get a cheat sheet that fits it.

Works on: Your own servers only.

## Prompt

```text
Read CLAUDE.md. Help me use GM commands on my own <Play Solo / hosted / dedicated> realm: explain how to give my account GM level 3 there, then write me a one-page cheat sheet as Agent\gm-cheatsheet.md with the commands I'll use most (teleport, level up, add items, spawn and delete NPCs, server info), checked against this server's own .help output where you can.
```

## Tips

- GM powers only exist on realms you run yourself.
