# Tour my Open Vanilla folder

A safe first prompt: the agent looks around and explains what is where. It changes nothing.

Works on: Your copy, read-only.

## Prompt

```text
Read CLAUDE.md, then look around this Open Vanilla folder without changing anything. Tell me in plain words: which addons I have in AddOns\Enabled and what each one does, whether Play Solo is set up (Realms\), and anything in Logs\ that looks like an error. End with three things you could help me do next.
```

## Tips

- Good to run first: it shows the agent has read the rules.
