# Change my realm's XP rate

Faster (or slower) levelling on your own Solo world or hosted realm.

Works on: Your own servers only (Play Solo, Open Vanilla Server).

## Prompt

```text
Read CLAUDE.md. I want <2x> experience on my own realm: <Play Solo / my Open Vanilla Server realm>. Find the right config file for that realm, back it up, and change Rate.XP.Kill, Rate.XP.Quest and Rate.XP.Explore. Show me the lines you changed, how to restart the realm, and how to undo it.
```

## Tips

- This only affects realms you run yourself. The official realm's rates can't be changed from here.
