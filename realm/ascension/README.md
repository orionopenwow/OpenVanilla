# Ascension Resurrected — planned, not built

A classless "Fun" realm: every character is an Adventurer who buys spells and talents from any class
with Ability Points and Talent Points, then shapes them with runes. It is listed as SOON™ on the website.

- `IDEAS.txt` — the original idea, as given.
- The full plan (engine limits found in our CMaNGOS tree, architecture, feature-by-feature design,
  balance and safety, a 7-phase roadmap, the testing plan, risks and the decisions still open) is the
  doc "Ascension Resurrected — Realm Plan":
  https://claude.ai/code/artifact/4e38d1b1-7935-442d-83c8-cdb559d892ac

Nothing is built yet. Phase 0 (a prototype on staging) comes first.
