# Warfront art wanted

The Warfront window works today with stock 1.12 icons (a PvP banner, class icons). These are the
pieces that would give it its own look. All of them must be **original art** (yours or generated),
never images taken from the game files: they ship to every player inside patch-Z.

Send PNGs at the size listed (or larger, same shape) with a transparent background where noted.
They are converted to 32-bit TGA for the game (1.12 needs power-of-two sizes) and to WebP for the site.

| # | Piece | Size | Background | Where it shows |
|---|---|---|---|---|
| 1 | Warfront crest (the realm's own emblem: crossed blades over a banner) | 256×256 | transparent | window title icon, minimap button, Classic+ menu row, site realm icon |
| 2 | Window header strip | 512×64 | opaque | top of the Warfront window behind the title and tabs |
| 3 | Tab icons: Kits, Gear, Shop, Shared sets, Arena | 64×64 each | transparent | the five tabs |
| 4 | Arena mode icons: 2v2 skirmish, 3v3 skirmish, 2v2 rated, 3v3 rated, 1v1 duel ladder | 64×64 each | transparent | beside each queue button |
| 5 | Tier badges: Starter, Tier 2, Tier 3 | 64×64 each | transparent | top-right of the window, gear picker locks |
| 6 | Bounty mark (a skull with coins) | 64×64 | transparent | "on a streak" chat line and "Bounty collected" toast |
| 7 | Realm bot mark (a plain cog or helm, clearly "bot", not cute) | 64×64 | transparent | the "bots in this battle" toast and the site's live line |
| 8 | Ring of Law backdrop (an arena floor seen from above, dark) | 512×256 | opaque | faded behind the Arena tab |
| 9 | Pop / Victory / Defeat splashes | 512×128 each | transparent | match found, end of match |
| 10 | Site: live panel icons (arena, battleground) | 96×96 each | transparent | the Warfront section's "Live now" line |

Style to match: the realm icon set already on the site (`www/assets/realm_ui/realm_icon_warfront.webp`):
embossed metal, warm red and gold, a soft drop shadow, readable at 32 px.

Highest value first: 1, 3, 4, 7. The rest can come later.
