Playing from your own game folder

  1. Check your version: the login screen shows build 5875 in the bottom-left corner, or right-click WoW.exe → Properties → Details.
  2. Install the Open Vanilla launcher.
  3. In the launcher, press CHOOSE FOLDER (or the grey PLAY button) and pick the folder with WoW.exe. The launcher checks it's the right client (build 5875) and remembers it.
  4. Press PLAY. The launcher writes the realmlist for you and backs up the old one.

Setting it by hand instead? Put this line in realmlist.wtf in the game folder: set realmlist (realm address, posted in Discord)

No client handy? You can still try Open Vanilla in the browser from the home page, or host your own realm with the server software.
