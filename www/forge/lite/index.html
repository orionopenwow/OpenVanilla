    What next

    1. Download the project and unzip it anywhere.
    2. Open the folder in Vanilla Forge on your computer.
    3. Check: Forge looks over every row, ID and file and tells you what to fix.
    4. Test & Play: walk your pack in game, in a safe copy that never changes your own game.
    5. Publish to the Workshop so realms can install it.

    Models, art, maps, spawns and the 3D world tools live in the desktop app. Forge Lite writes the same project format, so you can keep working on this pack there.
