What you need

  • Windows 10/11, macOS (Apple Silicon or Intel), or Linux server (x86_64 or arm64).
  • About 15 GB free disk space (SSD recommended).
  • Your own Vanilla Client v1.3 (build 5875) game files (client guide).

Hosting Modes

H1: Home Host with Outbound Relay (Recommended)

Run the server on your PC. The Open Vanilla helper connects an outbound tunnel to our verified relay network: no router port forwarding or public IP exposure required.

H2: One-Click Cloud Realm

Deploy an always-on realm on Hetzner Cloud (CX23) or Oracle Cloud Always Free (Ampere A1 arm64) using automated cloud-init scripts. Maps remain host-provided.

Pocket Realm (In-Tab Showpiece)

WebAssembly + WebRTC DataChannel server running in a background WebWorker for rapid pack testing and zero-install co-op.

If something goes wrong

Helper not respondingEnsure Open Vanilla Server or the Launcher helper is running, or launch with python tools/host_api.py.
Friends cannot connectEnsure the relay connection is active or router ports 3724 & 8085 are forwarded in direct mode.
Tick time amber/redCheck companion bot count in the Bots tab or lower active entity caps.
