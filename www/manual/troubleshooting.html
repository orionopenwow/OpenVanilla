    Troubleshooting

    The common messages and fixes, for the launcher, the browser, the game and hosting, and where the logs are.

    On this pageFind your logsLauncher messagesBrowser messagesIn the gameHostingStill stuck?

    Find your logs #

    Launcher: Settings → Folders → Open logs. The files that matter are launcher.log, update.log and web-backend.log. Attach them to a bug report (they don't contain your password).

    Launcher messages #

    MessageFix
    CHOOSE YOUR GAME'S DATA FOLDERPress PLAY and pick your game's Data folder (or the folder with WoW.exe), or let it download a client
    Missing X.MPQ / X is damagedThat client is incomplete: pick another folder or Download & install
    This is build N; Open Vanilla needs Vanilla Client v1.3 (build 5875)Wrong version: Open Vanilla needs Vanilla Client v1.3 (English, build 5875)
    Wow.exe wasn't found therePick the folder that contains WoW.exe, not its parent
    SERVER OFFLINEThe realm is down; check #server-status on Discord, or Play Solo
    This realm has no website setPick another realm, or add its portal URL on the Realms page
    Open Vanilla is offlineThe central services can't be reached; you can still play Solo and join friends directly
    That isn't an Open Vanilla invite linkCopy the whole link again, or use Join by address
    Host key changedAsk your friend for a new invite link; don't join until they confirm
    The update couldn't be appliedIt retries next start; details in Logs\update.log
    Windows says Unknown publisherThe launcher isn't code-signed yet: More info → Run anyway, or check the checksum first

    Browser messages #

    See Playing in the browser. The usual fix for a black screen is updating the browser and graphics driver (the client needs WebGPU).

    In the game #

    ProblemFix
    A Vanilla Remastered window is lost off-screen/wnl reset
    The interface feels wrong after a change/setup and pick a preset, or /vanilla for pure Vanilla
    An addon errorsTurn it off in /addons; for your own addons ask an AI agent with the Fix an addon error prompt (AI)
    Stuck, dead in a bad spot, talents brokenHelp → Talk to a GM (Tickets)
    Quest pins or threat missingThose need the realm; on some realms they're not available

    Hosting #

    ProblemFix
    "Information is not valid" at loginReset the account's password in the server window
    The server window closes straight awayPython isn't on PATH: reinstall Python and tick "Add to PATH"
    The database won't startSomething else uses port 3310; close it
    Friends can't connectForward TCP 3724 and 8085; check your firewall; give them your public address

    More in the Host Guidebook's Troubleshooting.

    Still stuck? #

    Ask in the Discord help forum with what you did, what you expected, what happened, and your logs. Security problems: report them privately (security.html).
