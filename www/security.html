Security

Found a security problem in Open Vanilla? Thank you. Please tell us privately first.

How to report

  • Use GitHub's private report: Report a vulnerability.
  • Or message a moderator on the Open Vanilla Discord and ask for a private channel.
  • Please don't post details publicly until it's fixed, and don't access other players' accounts or data to prove a point.

What's in scope

The launcher, this website, the web backend (sign-up, password change, game relay) and the server package in the repository. Community servers and mods are run by their owners.

What we do

We reply within a week, fix serious issues first, and credit you in the patch notes if you'd like.
